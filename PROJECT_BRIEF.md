# MBSA @ UIUC Website — Project Brief

## Overview
Single-page website for the Muslim Business Student Association at the University of Illinois Urbana-Champaign. Design remixes the UMich MBSA website (https://www.mbsaumich.org) — same layout DNA, adapted content for UIUC chapter.

## Tech Stack
- Next.js 14 + Tailwind CSS (match the withocto-site setup)
- Framer Motion for animations (scroll reveals, stat counters)

## Design Reference
See DESIGN_SYSTEM.json for full extraction from the UMich MBSA Framer site. Dark navy theme, Satoshi + Instrument Serif typography, gradient text effects.
